carnet-de-voyage-crete — Face review tool

Drag-and-drop ou sélectionne src/data/photos.json. L'outil charge chaque photo depuis Cloudflare R2, détecte les visages en local, et propose un tag family: true quand un visage occupe plus que le seuil paramétré. Clique sur une vignette pour inverser le tag. Exporte le JSON final pour le passer à node scripts/apply-family-tags.mjs <file.json>.
